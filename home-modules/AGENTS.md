# Global Agent Rules

- Write in Simplified Technical English (ASD-STE100): short sentences, simple words, active voice.
- Keep answers short and direct.
- Follow DRY.
- Do not add low-value comments, docstrings, or unit tests. Use clear names for functions, variables, and constants so they need no comment.
- Always use subagents. Keep the main agent free.
  - Development work: use medium-size models (Sonnet, DeepSeek) at medium effort.
  - Review work: use top models (Opus, Kimi 3.1) at high effort.
